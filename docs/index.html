Three readings of the same districts

The methodology document is the published result. The Shiny dashboard is a weight simulator: it starts from defaults so someone can try other weights. Airtable was loaded from the published work, then lost country, admin name, and period on most Iran and Ethiopia rows.

Pick a country and a month. The first number is the dashboard at its default weights. The second counts conflict once and uses severity scales. The third also drops cyclone, which is a structural zero in every shipped month and is how Iran’s Airtable totals were reached.
